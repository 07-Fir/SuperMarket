# SQLite JDBC

本项目随附 Xerial SQLite JDBC **3.53.4.0**，含常见平台的本地 SQLite 库，可离线运行，不需要另外安装数据库服务。

- 项目与使用说明：https://github.com/xerial/sqlite-jdbc
- 下载来源：https://repo.maven.apache.org/maven2/org/xerial/sqlite-jdbc/3.53.4.0/sqlite-jdbc-3.53.4.0.jar
- SHA-256 校验值：同目录 `sqlite-jdbc-3.53.4.0.jar.sha256`，来自 Maven Central，下载后已校验。
- Xerial 许可证：Apache License 2.0。驱动及附带组件的许可证原文包含在 JAR 的 `META-INF/maven/org.xerial/sqlite-jdbc/LICENSE*` 文件中。

保存方式参考 SQLite 官方的 [事务原子性说明](https://www.sqlite.org/atomiccommit.html) 和 [外键约束说明](https://www.sqlite.org/foreignkeys.html)。
